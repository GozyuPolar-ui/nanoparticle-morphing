# Nanoparticle Morphing (starter)

React + React Three Fiber + shader partikel.

    npm install
    npm run dev

- Ganti teks: prop `text` di `App.jsx`
- Jumlah partikel: `PARTICLE_COUNT` di `App.jsx`
- Radius pengaruh kursor: prop `radius` di `ParticleText.jsx`
- Warna: `dust` dan `formed` di fragment shader
